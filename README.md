# derivator
Derivator is a software dedicated to the processing of experimental Stribeck curves obtained as outputs from any kind of tribometer

## Aim and scope

The script is solely devoted to performing polynomial function fits on multiple experimental raw data sets, plus computing the first derivative (slope) and extracting the corresponding X value for a user-defined slope.

## How to use
To run the script, you must have Python 3 installed. 
Moreover, the following libraries are required:
- tkinter
- numpy
- matplotlib

To install them, simply use the following command from your terminal:

```bash
pip install tkinter numpy matplotlib
```
